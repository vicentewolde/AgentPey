Checks, wallet by wallet, what AgentPey's signing pages need: a SEP-53 message signature that our server verifies, and a transaction signature. Testnet only. Nothing here moves money: the test transaction is checked by the server and never sent. Comprueba, wallet por wallet, lo que necesitan las páginas de firma de AgentPey: una firma de mensaje SEP-53 que nuestro servidor verifica, y una firma de transacción. Solo testnet. Nada de esto mueve dinero: el servidor revisa la transacción de prueba y nunca la envía.
