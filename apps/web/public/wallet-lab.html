Wallet labLaboratorio de wallets

Checks, wallet by wallet, what AgentPey's signing pages need: a SEP-53 message signature that our server verifies, and a transaction signature. Testnet only. Nothing here moves money: the test transaction is checked by the server and never sent. Comprueba, wallet por wallet, lo que necesitan las páginas de firma de AgentPey: una firma de mensaje SEP-53 que nuestro servidor verifica, y una firma de transacción. Solo testnet. Nada de esto mueve dinero: el servidor revisa la transacción de prueba y nunca la envía.

Pick the wallet to test. Use a testnet account.Elige la wallet que vas a probar. Usa una cuenta de testnet.

2. Sign a message (SEP-53)2. Firma un mensaje (SEP-53)

The same kind of message every sign-in asks for. The server checks it with the code the real pages use.El mismo tipo de mensaje que pide cada inicio de sesión. El servidor lo revisa con el mismo código de las páginas reales.

3. Sign a transaction3. Firma una transacción

A test transaction from your account. The server checks your signature and drops it; it is never sent to Stellar.Una transacción de prueba desde tu cuenta. El servidor revisa tu firma y la descarta; nunca se envía a Stellar.
