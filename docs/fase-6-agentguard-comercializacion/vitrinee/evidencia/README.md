# Evidencia

Salida cruda de los comandos clave de cada día: tests, tx hashes, ids de
contrato. Un archivo por día, `DIA-N.md`. Nunca se editan a mano después de
cerrado el día; si algo cambia, se agrega una sección con fecha.

Nunca contienen secretos. Antes de pegar una salida, revisar que no aparezca
ninguna llave `S...` ni API key.
