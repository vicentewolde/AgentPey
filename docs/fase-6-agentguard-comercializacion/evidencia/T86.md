Escribir en el formulario de DNS de Vercel quedó bloqueado para Claude Code en
esta sesión. Los `CNAME` los cargó el usuario.

```
dig +short www.agentpey.com CNAME         → agentpey.onrender.com.
dig +short realops.agentpey.com CNAME     → agentpey.onrender.com.
dig +short signaldesk.agentpey.com CNAME  → agentpey.onrender.com.
dig +short agentpey.com A                 → 216.24.57.1
(iguales contra 8.8.8.8 y 1.1.1.1)
```

Dominios en Render: `realops.agentpey.com` y `signaldesk.agentpey.com` los
agregó Claude Code, y `agentpey.com` lo agregó primero el usuario. Costo:
**3 dominios, 2 incluidos en el plan, 1 extra a USD 0,25/mes** (`www` va en el
par de `agentpey.com`).

**El par `www` salió al revés** (`C-115`):

```
agentpey.com      → 301 → www.agentpey.com
www.agentpey.com  → 404   (el gateway no conoce www)
```

El usuario decidió sacar `www` y confirmó el borrado en Render. Borrarlo se llevó
el par entero, y `agentpey.com` quedó sin servicio unos minutos:

```
curl https://agentpey.com/ → (35) SSL routines:ST_CONNECT:sslv3 alert handshake failure
```

Claude Code volvió a agregar `agentpey.com`. Render propuso "redirect
`www.agentpey.com` to `agentpey.com`" y lo verificó en el acto, porque el `A` ya
estaba cargado.

- **`.env.local` corrompido.** El archivo no terminaba en salto de línea, y la
  primera `F9_WEB_URL` quedó pegada a la línea de `REALOPS_AGENTPEY_API_KEY`.
  Esa corrida usó la web vieja y una key alterada. Se separó la línea con un
  reemplazo exacto y se comprobó sin imprimir el valor. Las `F9_*_URL` se
  sacaron al terminar.
- **Dos secretos quedaron visibles en la conversación.** Para diagnosticar lo
  anterior se imprimieron las últimas líneas de `.env.local`, con
  `REALOPS_AGENTPEY_API_KEY` y `SIGNALDESK_FACILITATOR_SECRET` enteros. **Hay que
  rotar los dos.** La key del partner ya estaba pendiente desde T84.
  `SIGNALDESK_FACILITATOR_SECRET` lo usan también los servicios viejos: conviene
  rotarlo después del día 2.
- **Costo de dominios mal calculado en la conversación.** Se dijo USD 0,75/mes;
  son USD 0,25/mes (§ 3).
