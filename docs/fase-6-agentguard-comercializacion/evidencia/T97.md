Y los tenants están namespaceados por partner — el id se deriva de él:

$ grep -n "newTenantId\|findTenantByExternalRef\|listTenants" packages/directory/src/directory.ts

## 4. La ayuda

```
$ pnpm run partner:key -- --help
Usage:
  pnpm run partner:key                          Show the key in use and what it is missing
  pnpm run partner:key -- --issue               Issue a new key for that same partner
  pnpm run partner:key -- --issue --partner ptn_…   …for a partner named explicitly
  pnpm run partner:key -- --revoke apk_… --yes  Revoke an old key, after the new one is live

Options:
  --name "<label>"    A name for the new key. Defaults to "<partner> — rotated <date>".
  --scopes a,b,c      Permissions for the new key. Defaults to every permission.
```

---

## 5. Las protecciones del modo destructivo

Revocar es lo único que rompe algo, así que:

- exige el id explícito (`--revoke apk_…`),
- exige `--yes`; sin él imprime qué haría y no lo hace,
- **rechaza revocar la clave que está en `.env.local`**, con
  `ConfigError`, porque revocar la credencial que esta instalación usa nunca es
  la intención y un tipeo que lo hiciera tumbaría producción.

No se corrió `--issue` ni `--revoke`: emitir y revocar credenciales de
producción es del usuario (`P-10`).
