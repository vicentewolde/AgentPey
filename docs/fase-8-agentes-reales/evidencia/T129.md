Los pasos exactos para conectar cada uno están en `apps/mcp/README.md`
("Connect Claude", "Connect ChatGPT", "Pay a quote yourself"). Lo que el usuario

## 1. Claude (2026-10-03)

Conector personalizado en claude.ai: **Customize → Connectors → + Add → Add
custom connector**, URL `https://mcp.agentpey.com/mcp`, "Sign in when needed" y
la opción de cliente OAuth que Claude marcó como detectada. Inicio de sesión
con Freighter desde `GD2MCESI…K5GN`. El spec escribió "Settings → Connectors"
el 3-oct a partir de la documentación de ese momento; la interfaz de Claude hoy
lo llama "Customize → Connectors".

La compra es la de T128 (`evidencia/T128.md` §7), que cumple las tres partes
de `R-11`: Claude buscó y cotizó un imán en `agentcommerce`; se negó a llamar
`pay` y la persona pagó la cotización desde el MCP Inspector; y Claude leyó la
orden con `get_order` y su recibo (captura tomada después del pago, a pedido de
`/revisar`). Orden `ord_muszfkwz2604255e03`, pedido
Shopify `18990053523762`, tx `ba3abab7…6f70`, recibo con firma, anclaje y pago
en verde (verificado también por fuera en T128 §7.2).

## 2. ChatGPT (2026-10-03)

Cuenta Plus. **Settings → Security and login → Developer mode**; después
[chatgpt.com/plugins](https://chatgpt.com/plugins) → **+ Add → Create custom
MCP server**, con nombre `AgentPey`, una descripción breve, la URL
`https://mcp.agentpey.com/mcp` y OAuth. Estos menús no tienen captura; salen de
lo que el usuario contó mientras lo hacía. El registro y el inicio de sesión con
Freighter funcionaron a la primera: los dos riesgos que anotó el plan (la ruta
de los metadatos de recurso en la raíz y el valor de `resource`) no se
presentaron, y no se tocó el servidor de autorización.

En un chat con **+ → Developer mode → AgentPey**: "Use the AgentPey app to buy a
magnet in agentcommerce". ChatGPT encontró el producto, pidió los datos de
despacho, cotizó, preguntó "¿Confirmas que pague 1,5684211 USDC…?" y, con
"confirmo el pago", **llamó `pay` él mismo**. A diferencia de Claude (`R-11`),
no hizo falta el Inspector.
