## 2. La corrida

### A · Una compra con reclamo, respuesta y reembolso (T162, T163, T165)

1. **En Claude** (conector de AgentPey): «Busca un imán en agentcommerce y cotízalo, envío a <dirección>». Claude cotiza;
   la cotización dice que el pago queda retenido en el escrow.
2. **Pagar:** desde el MCP Inspector (`R-11`), con la misma wallet:

   ```bash
   npx @modelcontextprotocol/inspector@2.9.0
   ```

   `pay` con `confirm: true`. Anotar `order_id` y la transacción.
3. **En Claude:** «¿Dónde está el pago de mi pedido <order_id>?» → `get_order`: retenido.
4. **Despacho:** en el admin de Shopify (`agenticom`), marcar el pedido como despachado completo. En menos de 10 minutos
   (o al pedirle la orden a Claude) la ventana se abre: `get_order` dice `shipped` y hasta cuándo.
5. **Reclamo, dentro de esos 10 minutos:** en Claude, «No me llegó. Abre un reclamo por no entrega». Claude pide
   confirmación y llama `open_claim`: la respuesta trae `dispute.transaction`, `respond_by` y `claim_kept: true`.
6. **Respuesta del comercio, dentro de 15 minutos:** en el portal (`https://vitrinee.agentpey.com`), con la wallet de cobro
   `GD2MCESI…`, el pedido muestra «Reclamo abierto: responde antes del …» → «Responder el reclamo» → posición, descargos →
   firmar con Freighter o xBull. Anotar el hash de `respond`.
7. **Veredicto, sin archivos:**

   ```bash
   pnpm run resolve:decide -- --order agentcommerce.vitrinee.agentpey.com/orders/<order_id>
   ```

   Confirmar el hash del veredicto apenas sale (`E-18`):

   ```bash
   pnpm run resolve:execute -- --receipt <receipt hash> --confirm <verdict hash>
   ```

   ```bash
   pnpm run resolve:verify -- --receipt <receipt hash>
   ```

8. **En Claude:** `get_order` → resuelta, con el reembolso.
9. **Registro de avisos:** antes de cualquier deploy,

   ```bash
   curl -s https://agentpey.com/ucp/webhooks/orders
   ```

   y la cola de la orden en el log de Render (`order webhook delivered`), unidos por `webhookId`.

publicado de la extensión. Prueba nueva en `apps/web/src/ucp-webhooks.test.ts` (sin reembolso, reembolso parcial y total).
