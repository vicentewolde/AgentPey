## Namespace y origen — `docs/specification/overview.md`, líneas 82 a 104

```
The `spec` and `schema` fields are **REQUIRED** for all capabilities. The origin
of these URLs **MUST** match the namespace authority:

| Namespace       | Required Origin           |
| `dev.ucp.*`     | `https://ucp.dev/...`     |
| `com.example.*` | `https://example.com/...` |

Platform **MUST** validate this binding and **SHOULD** reject capabilities where
the spec origin does not match the namespace authority.

| `com.{vendor}.*`  | {vendor}.com | Vendor organization |

The `dev.ucp.*` namespace is reserved for capabilities sanctioned by the UCP
governing body. Vendors **MUST** use their own reverse-domain namespace for
custom capabilities.
```

Extensiones de terceros, línea 206:
`- **Vendor**: `com.example.installments` extends `dev.ucp.shopping.checkout``

## Quién escribe un handler — `overview.md`, líneas 1185 a 1191

```
- **Payment Credential Provider** = The participant (entity like Google Pay, Shop Pay)
- **Payment Handler** = The specification the provider authors (e.g., `com.google.pay`, `dev.shopify.shop_pay`)

Payment handlers allow for a variety of different payment instruments and
token-types to be supported, including network tokens. They are standardized
definitions typically authored by payment credential providers or the UCP
governing body.
```

Las tres etapas (líneas 1173 a 1175): Negotiation (Business → Platform),
Acquisition (Platform ↔ Payment Credential Provider), Completion
(Platform → Business).

## Declaración del handler — `docs/specification/payment-handler-guide.md`

Variantes (línea 202 en adelante): `business_schema` (perfil del comercio),
`platform_schema` (perfil de la plataforma) y

```
| **response_schema** | Checkout/Order API responses | **Runtime configuration** with resolved
context: merchant identity, resolved `available_instruments` for this checkout, tokenization
specs, and other state needed to process the transaction. Platforms **MUST** treat this as
authoritative. |
```

Adquisición del instrumento (línea 688 en adelante):

```
Payment handler specifications do NOT need to define a formal process for
instrument acquisition. Instead, the specification **SHOULD** clearly document:
- How to apply the handler's `config` to construct a valid `checkout_instrument`.
- How to create an effective credential binding to the specific checkout and
  business for usage, which is critical for security, based on the available
  `config` and `checkout`.
```

Binding (línea 755): "A cryptographic or logical association of a payment
instrument to a specific checkout transaction and business identity."

Errores (línea 744): "The specification **MUST** define a mapping for common
failures (e.g., 'Declined', 'Insufficient Funds', 'Network Error') to standard
UCP Error definitions."

resultados. `gh search issues` en el repo con `x402 OR stablecoin OR crypto OR
stellar`: sin resultados.

## Esquemas — `source/schemas/shopping/`

| Esquema | `additionalProperties` | `required` |
|---|---|---|
| `types/payment_instrument.json` | `true` | `id`, `handler_id`, `type` |
| `types/payment_credential.json` | `true` | `type` |
| `checkout.json` | `true` | `ucp`, `id`, `line_items`, `status`, `currency`, `totals`, `links` |
| `order.json` | sin declarar | `ucp`, `id`, `checkout_id`, `permalink_url`, `line_items`, `fulfillment`, `currency`, `totals` |
| `types/order_confirmation.json` | sin declarar | `id`, `permalink_url` (más `label` opcional) |

`types/amount.json`: "Monetary amount in the currency's minor unit as defined
by ISO 4217. Refer to the currency's exponent to determine minor-to-major
ratio (e.g., 2 for USD, 0 for JPY, 3 for KWD)." Tipo `integer`, mínimo 0.

`checkout.json` → `currency`: "ISO 4217 currency code reflecting the
merchant's market determination."

`checkout.json` → `status`: `incomplete`, `requires_escalation`,
`ready_for_complete`, `complete_in_progress`, `completed`, `canceled`.

`order.json` → `adjustments`: "Post-order events (refunds, returns, credits,
disputes, cancellations, etc.)"; en `order.md` el tipo es "an open string".
