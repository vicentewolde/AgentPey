## 4. Correcciones de `/revisar`

Sin bloqueantes. Corregido antes del merge:

- El test del layout fija nombre **y tipo** de cada campo de `Dispute` y que se
  lee de almacenamiento persistente (con otra durabilidad la clave cambia y toda
  orden diría "sin disputa" sin aviso).
- Test del RPC que nunca responde: la orden sale con `dispute_state_unavailable`
  (timeout inyectable, 50 ms en el test).
- El timeout es un `VitrineeError("NetworkError")`.
- `AGENT_RESOLVE_CONTRACT_ID` en `.env.vitrinee.example`.
- El id del contrato se lee de `deployments/testnet.json` con zod; uno inválido
  se descarta y la tienda arranca igual.
- Una disputa que el contrato nunca podría guardar (reembolso negativo o mayor
  que lo bloqueado, fecha imposible) se rechaza al decodificar: la orden da el
  aviso, no un 500.
